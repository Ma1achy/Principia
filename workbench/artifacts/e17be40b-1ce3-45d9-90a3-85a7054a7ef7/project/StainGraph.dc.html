Stain

THE DATA DOESN'T CHANGE. ONLY THE INK.

This is the back of the print. A stain decides what colour each point is printed in: it reads what was measured at that point and returns a colour. It can never change what was measured, only how it looks. Pick a stain from the library, rewire it as a graph, or open its code; the preview follows every change. How it is laid down — watercolour, pencil, print — is chosen in the bar above: the stain picks the colours, the style picks the hand.
