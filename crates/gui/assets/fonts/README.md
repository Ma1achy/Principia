# Fonts

`UbuntuMono-R.ttf` is Ubuntu Mono Regular, from the Ubuntu font family's upstream release 0.83, unchanged. It is egui's
`Monospace` family in the dev GUI (render_gui_spec §G1; RQ-251, `crates/gui/src/theme.rs`). Text keeps egui's own
Ubuntu Light, which egui ships.
