## Goal
On the mock engine (R-627; R-390's track), the Explore page's frame is the shell the human runs with `cargo run -p gui --features mock`: the top bar with the File / View / Windows / Help menus, the Explore / Stain switch, the Overlays ▾ / Run… / Profiler… / Export… entry points, the keyboard breadcrumb slot, and the status line (t, fps, frame ms, quad count, undo / redo depth, "F3 hide") read from the mock's snapshot; the footer with warning and error counts, the latest message, memory and "? keys". Nothing is drawn over the figure: warnings go to the footer. It extends the track's shell (TASK-M6-24, TASK-M6-30, TASK-M6-46, TASK-M6-47, TASK-M6-49). Its wiring to the real engine (egui-wgpu on the engine's device and queue, the real status line and its `budget-bound`) is TASK-M8-88's; the figure past `[0,1]²`, the axis extension types and the area statistics are TASK-M8-87's. It is the first of M8's track tasks (R-627).
