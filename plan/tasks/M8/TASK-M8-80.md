# TASK-M8-80 — Export details: every measured colour window frozen at export and at Record, the clipped shares and the export block, the colour-vision simulation never in an export unless asked, `render_scale` 1, and the physical size (R-581 to R-583)

- **Milestone:** M8
- **Closes:** REQ-RENDER-117, REQ-TOOL-201, REQ-TOOL-202, REQ-GUI-389, REQ-TOOL-203, REQ-TOOL-204, REQ-GUI-390, REQ-TOOL-205, REQ-TOOL-216, REQ-TOOL-217, REQ-TOOL-218

- **Needs (earlier milestones):** REQ-RENDER-118
- **Reviewers:** code, qa, gui
- **Pitfalls:** none
- **Size:** ~600 lines, the tests included

## Goal
An image export freezes every measured colour window at the window on screen when Export is pressed, into `RenderState.frozen_ranges`, and `range_norm` reads a frozen window as its third source; Record a time sweep freezes at Record, per frame an explicit labelled choice and an opt-in low-resolution pre-pass freezing the union of every frame's window another, and the Sequence's export at its Start; every export carries the export block (`range_policy`, the clipped shares, `cvd_simulated`, `render_scale`, the `device_px` nodes) as a sidecar outside the identity; an imported frozen node reads "frozen at export" until Re-measure. The colour-vision simulation is `ViewUI.cvd`, never in an export unless "As seen with" is picked; every export renders at `render_scale` 1; an optional physical size sets the width and writes `pHYs`; the GUI's save and Export & share writers write `base_width` in logical px (R-581 to R-583).

## Acceptance tests
- `cargo test -p render frozen_range_roundtrip` — a 4× image export of a view with two measured nodes and one declared writes both measured nodes' on-screen u_range into frozen_ranges and gives the declared node no entry, and its export block's froze.nodes lists exactly the two measured nodes; importing it and rendering at the export's size gives pixels bitwise equal to the export, each frozen node reading its entry and not measuring; a second export of the imported view, whose nodes are already frozen, lists no node in froze.nodes; a snapshot JSON of the same view writes no entry (controls: an import that re-measures, an export that measures its window over the 4× pixels, an export whose froze.nodes omits a node it froze, and one whose froze.nodes lists a node the view had already frozen, each fail) (REQ-RENDER-117).
- `cargo test -p gui recording_one_window` — a 10-frame sweep of a view with a measured node records an equal u_range in every frame's record, equal to the window on screen when Record was pressed, and range_policy frozen (control: per frame gives at least two distinct windows and records per_frame); the dialog's per-frame option is off by default and carries its label; a Sequence fixture of two keyframes, the second's stain holding a node the first's lacks, freezes the first's node at Start and the second's at its first frame, both named in the planner and the record (control: a Sequence export that re-measures every frame fails) (REQ-TOOL-201).
- `cargo test -p render clipped_share_counts` — a fixture field forced past its frozen window's hi on a quarter of the system pixels reports clipped (0, 0.25) for that node, the not-a-system pixels counted at neither end; a 3-frame recording carries three maps in frame order; the export block reads back from the tEXt chunk and from the low-bit record's tier 2, and importing the export restores SimConfig and RenderState bitwise without the block in either; a headless export of a state that already carries frozen_ranges and a base_width reports froze { nodes: [], base_width: null } and leaves both fields as the state had them (controls: a share that reads 0, one that counts not-a-system pixels, a block missing from tEXt, and a headless export that reports a node or a base_width, each fail) (REQ-TOOL-202).
- `cargo test -p gui frozen_at_export` — after importing an export with two frozen nodes, a node's inspector and its Legend key read "frozen at export"; Re-measure removes only that node's entry, sends one SetField on FrozenRanges and adds one undo entry, the node then measuring; undo restores the entry; deleting a frozen node drops its entry in the deletion's one undo entry, undo restoring node and entry, and a new node given the deleted node's id measures; loading a preset drops every entry of the replaced graph (controls: a Re-measure that clears both nodes, one that adds two undo entries, a stale entry that freezes a new node with a reused id, and a drop that adds its own undo entry, fail) (REQ-GUI-389).
- `cargo test -p render cvd_not_in_export` — with ViewUI.cvd at deuteranopia an export's pixels equal, bitwise, the same export with it off, and its record carries cvd_simulated null; with As seen with picked the pixels differ from those and equal the simulation applied to them, the record carries deuteranopia and the file name ends __as_seen_deuteranopia; importing that file reports it and leaves ViewUI.cvd as it was (controls: an export that bakes the simulation without the choice, and one that picks it but records null, fail) (REQ-TOOL-203).
- `cargo test -p render render_scale_forced` — an export made with the view at render_scale 0.5 equals, bitwise, the same export made at render_scale 1, and its export block records 1 (control: an exporter that inherits the view's render_scale fails) (REQ-TOOL-204).
- `cargo test -p gui cvd_viewer_setting` — changing the simulation sends no SetField and adds no undo entry; the view's snapshot JSON and pxpack carry no cvd field; the setting is restored from the GUI's settings after a restart; the As seen with checkbox is absent with the simulation off and present and unticked with it on; Import picture's preview of an As-seen export shows the badge inside the header strip's rect and outside the plot's (controls: a change entering undo, a record carrying cvd, the checkbox ticked by default, and a badge drawn over the plot, each fail) (REQ-GUI-390).
- `cargo test -p render physical_size` — an export of 100 mm at 300 DPI is 1181 px wide with pHYs 11811 pixels per metre, unit 1; a 2 base px stroke on a base_width of 1024 reads 0.554 pt to three places; an export with no physical size writes no pHYs (controls: a pHYs in pixels per inch, and a pt value stored on the style as a unit, fail) (REQ-TOOL-205).
- `cargo test -p gui recording_prepass` — a 10-frame sweep of a view with one measured node whose window widens over time, recorded with the pre-pass picked, records the same u_range in every frame's record, equal to the union of the windows the pre-pass measured per frame, with range_policy prepass_union and one clipped map per frame; the pre-pass is offered, off by default, in the Record dialog and in the Sequence's planner; with it off the window is the screen's at Record and range_policy frozen (controls: a pre-pass window taken from the final frame only, one taken from the first frame only, a pre-pass rendered at the recording's full resolution, and a pre-pass on by default, each fail) (REQ-TOOL-216).
- Calibration: the PR proposes the resolution with its evidence (the pre-pass's time against the recording's on the reference machine, and how far the union at that resolution falls inside the full-resolution union over the fixture sweeps, as the clipped shares it leaves); a reviewer checks it; the human confirms it at the M8 gate (REQ-TOOL-217).
- `cargo test -p gui base_width_writers` — a GUI save of a view 1600 logical px wide writes base_width 1600, and a 1× and a 2× export of a view 800 logical px wide are 800 and 1600 px wide with base_width 800 and froze.base_width 800, each at display scale factors 1 and 2; importing the 2× export and the save into a window 1200 logical px wide gives back base_width 800 and 1600 bitwise (controls: a writer that keeps a stale base_width on a GUI save, an export width counted in physical px, an importer that rewrites base_width to the live window's width, and an export whose froze.base_width is null, each fail) (REQ-TOOL-218).
