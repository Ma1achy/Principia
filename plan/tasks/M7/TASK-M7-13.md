## Goal
The fragment registry is generated by scanning `shaders/wgsl/frag/{colour, brightness, combiner, post, debug}`: adding a `.wgsl` file registers an occupant with no code edited, runtime-authored customs join the same way, and the fixed compositor passes are not scanned. Entries are {id, slot, source, category, uniformSchema, inputDomains} keyed by directory, an occupant is valid only in its slot, and every entry carries inputDomains (R-53): the manifest's per-field domain by default, a node that transforms its field declaring its own.
