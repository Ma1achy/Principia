# TASK-M7-56 — Print graph port, Analyse and Generate: 5 node types, each with its lab golden (R-486, R-492)

- **Milestone:** M7
- **Closes:** REQ-COL-142, REQ-COL-143
- **Depends on:** TASK-M7-55
- **Needs (earlier milestones):** none
- **Reviewers:** code, qa, gui, perf
- **Pitfalls:** none
- **Size:** ~900 lines, the tests and the fidelity harness included

## Goal
Port the lab's Analyse and Generate category to WGSL, one node at a time against the lab's own output: brightness, flow, edges, noise, paper. Each node's registry entry is written from `catalogue/node_catalogue.json` (its `doc`, typed inputs and parameter ranges, each length with its unit), with its provisional cost class and motion policy, `temporally_stable`, and every deviation the design requires listed, never tuned to match (R-492). No lab preset is completed by this category. Goldens: each node at its defaults on the bundled source image against `images/nodes/`, each preset against `images/presets/`, within REQ-COL-142's tolerance; the scale (§11 test 4) and stability (test 5) harnesses run on the category's nodes. As the first port task it builds the fidelity harness (ΔE in OKLab, median and p99, against the lab's reference images; the 512² JPEGs, or exact PNGs regenerated by the bundled `tools/capture_nodes.js`, R-492) and proposes the tolerance every later port task uses (REQ-COL-142).
