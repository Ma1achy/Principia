## Acceptance tests
- `cargo test -p engine backwards_table_cpu` — for each kernel chart of the first slice, a baked backwards table and search on the CPU return every forward node to its own cell. Measurement: at `t = 0` and after a run, 256 × 256 samples, table 64, scan 16 (the prototype's sensible point, re-measured, not adopted): the wrong share (a worse match than an exhaustive search of the same table) and the round-trip error in cells; criterion written before any run: PASS if the wrong share at `t = 0` is at most the prototype's figure for the same kind of chart (0.00% on the plain sphere and latent charts, 0.12% on `(L_z, E)`); EXPLAINED DIVERGENCE if worse with a named cause; else UNEXPLAINED. The accuracy outside a morph is R-935's (under RQ-767 (a): the table seeds a refinement on the chart's forward code) (REQ-CHART-192).
- `cargo test -p engine backwards_table_blend` — the re-plan's open item O4 (the chart audit's F23, item 4; criterion written before any run): at `t = 0`, 256 × 256 samples, table 64 and 128, scan 16, the latent chart to the exponential-map sphere at `s = 0.25`, 0.5 and 0.75: the wrong share by route (baked, scan), and the folded share by TASK-M2-90's signed fold indicator. PASS if the wrong share outside folded cells is at most this task's figure for plain charts of the same kind (0.00% on the plain sphere and latent charts); EXPLAINED DIVERGENCE if the excess lies in folded cells (R-936: where a blend folds there is no true copy, the nearest answers, labelled) or has another cause the physics reviewer names; else UNEXPLAINED. Positive control: a table off by one node raises the wrong share, or the run is void (REQ-CHART-192).
- `cargo test -p engine backwards_table_size_gauge` — the re-plan's open item O9 (the chart audit's F23, item 4): the kernel's encode (step 0, `canon.rs`) reused, never a new map; a backwards round trip on states on the chart's own image, each also taken at a size `I ≠ 1`; two checks: the chart point found for the state at `I ≠ 1` equals the one found for the same state rescaled to `I = 1`, within the stated tolerance, and the decode equals the state's canonical form (REQ-ENC-006, the size gauge); control: an unrescaled lookup lands on a different chart point and fails the first check (REQ-CHART-192).
