## Goal
**R-444 to R-448 (16 Oct 2026):** the outcome view shows physical outcomes only. Its nine classes are bounded / nothing
yet `#141418`, collision 1–2, 1–3 and 2–3, triple collision `#F29620`, the escapes of body 1, 2 and 3, and triple
ejection `#611597` (named as shown, R-449; internally pairs 2, 1, 0 and `detail` 0, 1, 2), read from `state` and `detail` alone: a collision at `t_end_step == 0` draws its pair's or the
triple collision's colour, and there is no "degenerate" or "collision @ t=0" class. Black means nothing has happened
yet: `running`, `sim_failed`, every `decode_failed` and a reserved `state` code draw `#141418`, not the "not yet"
stipple or the hatch, which stay the debug views' and every other field's. A sample in a forbidden chart region keeps
the hatch, decided from the chart's own classification, never from the payload's `decode_failed` detail; this task
defines how that classification reaches the view (R-72). The OKLab-uniform variant is a second swatch set, the sRGB
palette the default. Greyscale and hue mode rank the nine classes, `K = 9`. TASK-M1-10, TASK-M1-14 and TASK-M1-17 built
the palette, its modes and its not-yet class and have merged, so the change needs its own PR, as R-436 added
TASK-M2-31.
