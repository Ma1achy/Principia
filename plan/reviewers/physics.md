# Physics reviewer — checklist

Named on every task that touches decode, encode, charts, the integrator, events, payload physics fields, any numerical
gate, any R-71 calibration of a physical value, any R-72 definition, or any pitfall regression (`plan/WORKFLOW.md` § "Task files").
Answer each item yes / no / not applicable on the PR; a "no" is a finding and cites file and line of the diff or the
section below (`plan/WORKFLOW.md` § "The review loop").

## 1. Numerical gates

The rule: **every numerical gate the task closes is run and its threshold met, or — where the corpus gives no threshold —
its calibration requirement's proposal is attached** (`decisions.md` § "R-71 — A missing value becomes a calibration requirement *(closes RQ-46 to RQ-55, values)*"; `plan/WORKFLOW.md` § "Human checkpoints: the milestone gates").

- [ ] Every `numerical gate` requirement the task closes has an acceptance line (`cargo xtask gate <gate>`) whose output is in the PR description, and the threshold it passed is the requirement's own, or its calibration requirement's proposed value — never one chosen in the PR. `plan/WORKFLOW.md` § "The unit: one task, one branch, one PR"; `decisions.md` § "R-71 — A missing value becomes a calibration requirement *(closes RQ-46 to RQ-55, values)*"
- [ ] No gate threshold was loosened, re-scaled or re-expressed between the first red run and the green one without an RQ and a ruling. `docs/read_first/principia_00_philosophy.md` § "4.2 Every constant must be derived or absent"; `decisions.md` § "Porting rule — a port adds, it never removes a decision"
