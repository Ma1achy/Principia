Principia — Render-Mode Catalogue

A render mode = a field out of ctx + a type and its default mapping. This catalogue foregrounds the mapping — the gradient / palette and its polarity — since that is the design decision; the shape-sphere colour-map editor is one mode (n̂ → SiteBlend). Every default is customisable. (Click a mode for the mapping enlarged + an applied example on an illustrative slice.)
Polarity is chosen per field so the salient end is bright: FTLE / diffusion → white = high (chaos, spreading pop); ensemble spread → white = low (a confidence measure — high dispersion is untrustworthy, recedes to black); time-to-event → white = early (quick-resolving pops, late / bounded darken → consistent with bounded = black). Greyscale is deliberate: a magnitude field is a lightness, so it drops straight into the brightness slot — colour = n̂ × brightness = ⟨field⟩ falls out for free. Signed fields (energy, L_z) use diverging-through-neutral so the zero-crossing is legible; angles use cyclic; enums use palettes. Addressing views use a channel convention so they read apart at a glance: UV → red+green, top-left → red+blue, centre → blue+green, index → greyscale. Quad & tile boundaries are NOT a fragment colour map — they are a separate overlay / line pass (a post-chain band-mask on distance-to-edge) drawn over whatever mode is active, so any mode above can be shown with the mesh on top.
