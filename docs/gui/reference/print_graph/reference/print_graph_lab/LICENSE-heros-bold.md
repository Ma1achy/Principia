# heros-bold.otf

The font beside this note, `heros-bold.otf`, is **TeX Gyre Heros Bold** (version 2.004), unmodified.

Its copyright line, as the font's own name table gives it:

> Copyright 2006, 2009 for TeX Gyre extensions by B. Jackowski and J.M. Nowacki (on behalf of TeX users groups).

It is released under the **GUST Font License**: http://tug.org/fonts/licenses/GUST-FONT-LICENSE.txt

It is here only because the reference lab's page (`index.html`) loads it; nothing in Principia's build uses it.
