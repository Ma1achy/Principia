The Print row is shown on paper, not over the field: a style can be sized in points for an exported print, where screen pixels mean nothing.

What a style holds
stroke colour · width · opacity · cap · join
dash solid | dashed | dotted | dash-dot | pattern [on off …]
outline colour · width (drawn under the stroke, same dashes)
ink fixed | smart(radius, hysteresis, mode)
label font · size · format · halo · gap · upright
units screen px | print pt
Rules
  • A line refers to a style by name and may override single fields.
  • Editing a style updates every line that uses it.
  • Styles are display settings: they never re-integrate.
  • Saved in the exported view, so a print reproduces its lines.
